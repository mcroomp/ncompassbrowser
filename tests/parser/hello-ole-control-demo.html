Hello OLE Control

This page hosts HelloOleControl.dll, a tiny purpose-built ActiveX/OLE control (see hello-ole-control/) created specifically to demonstrate the browser's historic <xolecontrol> OLE hosting feature, exercised end-to-end through the browser's own original, unmodified CControlItem code (win32/cntlitem.cpp).

The control's persisted state (hello.olestate) was generated with ncompass-debug.exe --make-ole-state.
